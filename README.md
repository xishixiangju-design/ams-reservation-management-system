# AMS予約管理システム

## 概要

サービス業向けの予約・業務管理システムです。

予約管理、スタッフ管理、顧客管理、売上・収益管理などの業務機能を実装しました。

また、RBAC（Role Based Access Control）による権限管理機能と、
Difyを利用したAIチャットによる業務支援機能を追加し、
店舗運営における情報管理と業務効率化を目的として開発しました。


## 開発目的

サービス業では、予約情報、スタッフ情報、売上情報など、
複数の業務データを効率的に管理する必要があります。

本システムでは、以下の課題解決を目的として開発しました。

- 予約情報の一元管理
- スタッフ業務管理
- 売上・収益データ管理
- 権限による安全な情報管理
- 問い合わせ対応の効率化


## 主な機能

## 1. 予約管理機能

- 予約情報の登録・編集・削除
- 予約一覧表示
- 予約ステータス管理
- 担当スタッフとの紐付け


## 2. 顧客管理機能

- 顧客情報管理
- 利用履歴管理
- 顧客情報検索


## 3. スタッフ管理機能

- スタッフ情報管理
- 担当業務管理
- スタッフ別の予約管理


## 4. 売上・収益管理機能

- 売上情報登録
- 収益データ管理
- 売上履歴確認
- 業務データ分析用情報管理


## 5. 権限管理機能（RBAC）

Role Based Access Controlを利用し、
ユーザーの役割に応じたアクセス制御を実装しました。

例：

- 管理者：全機能利用可能
- スタッフ：担当業務・予約情報の管理
- 一般ユーザー：限定機能利用


## 6. AIチャット機能

Difyを利用したAIチャット機能を実装しました。

処理フロー：

1. ユーザーから問い合わせを受付
2. 問い合わせ内容を分類
3. ナレッジベースから関連情報を検索
4. AIによる回答生成


業務マニュアルやFAQ情報の検索を効率化し、
スタッフの問い合わせ対応を支援します。
